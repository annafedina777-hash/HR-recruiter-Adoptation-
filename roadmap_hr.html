Как получить SYNC_URL (один раз, 5 минут)

  1. Откройте script.google.com → «Новый проект».
  2. Удалите весь код в редакторе и вставьте вместо него: function doGet(e){ var p = PropertiesService.getScriptProperties(); var v = p.getProperty(e.parameter.key || 'default') || ''; return ContentService.createTextOutput(v).setMimeType(ContentService.MimeType.JSON); } function doPost(e){ var p = PropertiesService.getScriptProperties(); p.setProperty(e.parameter.key || 'default', e.postData.contents); return ContentService.createTextOutput('{"ok":true}').setMimeType(ContentService.MimeType.JSON); }
  3. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение». Кто имеет доступ — «Все» (Anyone). Нажмите «Развернуть» и разрешите доступ своему аккаунту.
  4. Скопируйте выданную ссылку (заканчивается на /exec) и вставьте её в поле SYNC_URL вверху карты, нажмите «Подключить».
  5. Дайте ту же ссылку стажёру и наставнику — все, кто впишет её в это поле на своём устройстве, увидят один и тот же прогресс.
